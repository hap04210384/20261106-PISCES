E-B10 real-bitmap baseline rerun summary (2026-11-02)
=========================================================
Instance: kpn_planted150 (real K. pneumoniae cohort bitmap, 1,992 genomes x
54,590 gene families), identical instance to the headline 84/150 result.
Protocol: per planted pair, both directions; significance = Bonferroni
0.05/54590 = 9.16e-7 (pyseer) / Scoary's own Bonferroni column < 0.05;
Scoary pair called when BOTH directions significant.

Recall (pair-level):
  Ours (exact screen)         84/150  (cooc 50, cond 33, mutex 1)
  Scoary 1.6.16 --no_pairwise 80/150  (cooc 50, cond 29, mutex 1)
  pyseer FE (--no-distances)  79/150  (cooc 48, cond 30, mutex 1)
  pyseer LMM (distances)     17/150  (cooc 1,  cond 16, mutex 0)

p-value head-to-head (ours exact Fisher vs pyseer FE LRT p, min over
directions, n=46 pairs where both finite):
  median log10(ours) - log10(pyseer) = +1.05
  ours more significant in 46/46 pairs, in EVERY magnitude bucket
  (-inf..-100: +1.23; -100..-50: +0.98; -50..-20: +1.05; -20..-10: +0.64;
   -10..-5: +0.77; -5..-2: +0.68)
  => the asymptotic LRT is systematically ~1 order of magnitude more
     conservative than the exact Fisher test on this cohort.
  Discordance at the Bonferroni threshold: 1/46 (pyseer significant,
  ours not; cond pair ours log10p=-5.46 vs pyseer -6.20).

Interpretation (replaces the dry-run "2.3x recall advantage"):
  The dry-run synthetic instance exaggerated baseline weakness. On the real
  cohort, structure-naive exact-statistics baselines (Scoary, pyseer FE)
  achieve recall statistically comparable to ours (79-84/150). The
  defensible advantages of our screen are: (1) exhaustive all-pairs
  counting without a candidate-gene step - pyseer/Scoary cannot enumerate
  1.49e9 pair tests at this scale, and per-gene pre-selection is exactly
  the step that discards the interacting partner; (2) exact Fisher vs
  asymptotic LRT (~1 log10 more power, uniform across magnitudes);
  (3) interaction-lab speed (sub-10-s counting wave vs hours of per-pair
  re-runs: 300 Scoary invocations x ~175 s each = ~14.6 h CPU for the
  150-pair benchmark alone); (4) mutex (mutual-exclusion) mechanism
  handled in the same pass; (5) structure-aware calling via
  lineage-stratified permutation recovers signal absorbed by kinship
  models (pyseer LMM 17/150).

semantics-preserving dict(zip()) fast path (identical output structure;
only parse speed). Statistics code untouched. Patched file lives in
