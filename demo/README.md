# Demo dataset (synthetic, ships with the repository)

`data/demo/demo_matrix.txt` is a **synthetic** GBM1 matrix: 2,000 genomes x 600 gene
families, generated by `gbm_count --gen 2000 600 7`, into which `gbm_sim --plant
6 8 4 304` planted 18 known interactions (6 co-occurrence, 8 mutual-exclusion,
4 conditional) with their ground truth in `truth.tsv`.

Because it is synthetic it is free of data-provider terms and may be redistributed;
the study-scale real-data matrices are **not** shipped (see the main README,
"Data availability" — download them from the public sources given there).

## Run it

```
bash demo/run_demo.sh        # Linux/macOS
demo\run_demo.bat            # Windows
```

The pipeline is the same one used at study scale: exact all-pairs count with the
hypergeometric deviation screen (`minc=3`, gate |z| >= 3.29), then a two-sided
Fisher exact test per screened pair, then comparison against the planted truth.
On a laptop it finishes in about a second.

## What to look for

- The screen emits only ~0.15% of all pairs (compare: 1.5% at study scale) —
  cost scales with emitted evidence, not with the pair space.
- All planted co-occurrence pairs, the strongly planted mutual-exclusion pairs
  and the strong conditional pair are recovered at tiny Fisher p-values.
- The deliberately weak planted pairs sit **below** the statistical gate and are
  correctly absent from the screened set. That is the intended behaviour: the
  gate is a power limit, not an error.
- `expected_stats.tsv` holds the reference statistics output; your run should
  reproduce it byte-for-byte (the engines are deterministic).
